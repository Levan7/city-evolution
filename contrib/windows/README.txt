City Evolution - Windows (64-bit)

HOW TO START
  1. Extract the WHOLE zip into a new folder (right-click the zip, Extract All).
  2. Double-click "City Evolution.exe".

WHERE THINGS ARE
  PortableData\          your saved cities and the startup log (launch.log)
  Settings\default.xml   settings
  Game\                  the game itself (do not mix with files from other versions)

"WINDOWS PROTECTED YOUR PC" OR "SCANNING" MESSAGES
  This program is not digitally signed: signing needs a paid certificate from a certificate
  authority. Windows therefore treats a freshly downloaded program as unknown.
  It is not a virus warning. To start it anyway:
    - In the blue "Windows protected your PC" window click "More info", then "Run anyway".
    - Or right-click the downloaded zip, choose Properties, tick "Unblock", press OK, and extract again.
  The full source code is published, so anyone can check what the program does.

IF THE GAME DOES NOT START
  Send the file PortableData\launch.log with a short description of what you saw.
